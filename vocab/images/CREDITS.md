# Image credits

Every icon here is a 64×64 SVG in the style of the flashcards in `index.html`
(a pastel circle with the motif drawn in a darker shade of the same colour).
The motifs come from the sources below. They were recoloured and scaled, and
otherwise left unchanged.

| source | licence | notes |

| Original `index.html` flashcard icons | same as this repository | reused for words already on the page |
| [Lucide](https://lucide.dev) v0.460.0 | ISC, © Lucide Contributors (portions © Cole Bemis, Feather, MIT); see `LICENSE-lucide.txt` | most line icons |

| [Health Icons](https://healthicons.org) | MIT, © Resolve to Save Lives | body parts |
